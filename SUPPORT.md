# Support / 获取支持

## Before asking for help

Before opening an Issue, please:

1. Read the README and existing Issues.
2. Confirm that you are using the latest script version.
3. Run the relevant operation again and collect sanitized logs.
4. Remove IP addresses, UUIDs, private keys, passwords, and proxy credentials.

## 提问前

提交 Issue 前，请：

1. 阅读 README 并搜索已有 Issue。
2. 确认正在使用最新脚本版本。
3. 重新执行相关操作，并收集已经脱敏的日志。
4. 删除 IP、UUID、私钥、密码及代理凭据等敏感信息。

Use the repository's Bug Report or Feature Request form for reproducible work.
General usage questions belong in
[GitHub Discussions](https://github.com/5548269/xray-reality-manager/discussions).
Security vulnerabilities must be reported privately according to [SECURITY.md](SECURITY.md).

可复现的问题请使用仓库提供的 Bug Report 或 Feature Request 表单。一般使用问题请前往
[GitHub Discussions](https://github.com/5548269/xray-reality-manager/discussions)。
安全漏洞必须按照 [SECURITY.md](SECURITY.md) 私下报告。
