# Maintainers / 维护者

## Primary maintainer / 主要维护者

- [@5548269](https://github.com/5548269)

The primary maintainer is responsible for issue triage, pull request review,
security-sensitive changes, upstream synchronization, release validation, and
release publication.

主要维护者负责 Issue 分类、Pull Request 审查、安全敏感修改、上游同步、版本验证及发布。

Contributions are welcome through public Issues and Pull Requests. Security
vulnerabilities must be reported privately according to [SECURITY.md](SECURITY.md).

欢迎通过公开 Issue 和 Pull Request 参与贡献。安全漏洞必须按照
[SECURITY.md](SECURITY.md) 私下报告。
